# Family apps

Information about two private applications used for personal and household planning.

- [FamilyPlanner](familyplanner/) helps manage family calendars and event coordination.
- [FamilyPlanner Sabueso](sabueso/) extracts proposed events from authorized email sources for FamilyPlanner.

These applications are operated privately. This website provides product information, privacy notices and terms; it does not offer public account registration.
