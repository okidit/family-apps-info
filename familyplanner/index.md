# FamilyPlanner

FamilyPlanner is a private application for personal and household calendar coordination.

It uses Google Calendar to read calendars and events, check availability, and create, update or cancel events in the calendars authorized for those operations. It also synchronizes subscribed event sources and tracks local planning and synchronization information.

Access to Google data requires the Google account holder's authorization. Calendar changes depend on configured permissions and requested or scheduled application operations.

FamilyPlanner is used by the operator and invited household members. It is not available for public registration. This public website does not provide access to household calendars.
